# LedgerLearn — CA & CMA Study Hub (MVP)

## Included
- Responsive web app suitable for mobile browsers
- Android-friendly Progressive Web App (PWA) shell
- CA and CMA study guide starter content
- Links to official ICAI / ICMAI learning and exam portals
- Sample MCQ practice with instant explanations
- Local bookmarks and practice stats
- Local display-name profile

## Run locally
Open `index.html` in a browser. For PWA installation/offline cache, serve the folder over HTTPS or localhost.

## Free hosting
Upload these files to a static host such as GitHub Pages or Cloudflare Pages. No paid services are required for this demo.

## Install on Android
1. Deploy the folder to an HTTPS static host.
2. Open the deployed URL in Chrome on Android.
3. Use Chrome menu → **Install app** or **Add to Home screen** (wording may vary).

## Important limitations
- This MVP uses browser localStorage. The profile is NOT secure authentication, and bookmarks/progress do not sync between devices or browsers.
- Real email/password login, cross-device sync, password reset and admin content management require a backend (for example, a free-tier Firebase or Supabase project) and configuration.
- Included MCQs and study guides are sample learning content, not official question papers or institute-approved notes.
- Past-paper section links to official portals; it does not redistribute copyrighted PDFs.
- Verify current syllabus, exam scheme and official resource URLs before relying on content for an exam.
